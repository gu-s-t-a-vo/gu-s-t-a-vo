# GU Panorama Character Pipeline

Этот аддон добавляет кинематографическую панораму при заходе на сервер Garry's Mod, последующую авторизацию/регистрацию и менеджер персонажей из трёх слотов с поддержкой DarkRP.

## Возможности
- **Панорама при входе**: полноэкранный фон с логотипом 900x400 по центру и мигающей подсказкой «нажмите любую кнопку чтобы продолжить».
- **Авторизация/регистрация**: поля логина, email, пароля и промокода, флажок «Запомнить меня» для автологина при следующем заходе.
- **Создание персонажей**: три слота, ввод имени/фамилии и возраста, настройка модели и bodygroup (сохраняются в `data/gu_panorama`).
- **Выбор персонажа**: отображение баланса, времени последнего входа, имени и фамилии; запуск в точке спавна или в позиции последнего выхода.
- **Интеграция с DarkRP**: синхронизация RP-имени и денег (если режим доступен на сервере).

## Установка
1. Скопируйте папку с файлами в директорию `garrysmod/addons/gu_panorama`.
2. Убедитесь, что материалы логотипа и фона доступны по путям из `lua/autorun/sh_gu_panorama_config.lua` (`materials/gu_panorama/logo.png` и `materials/gu_panorama/background.png`).

## Полезные команды
- `gu_panorama_reload` — принудительно перезагрузить данные и повторно показать панораму на клиенте.

## Потоки данных
Данные аккаунта и персонажей сохраняются на сервере в `garrysmod/data/gu_panorama/<steamid64>.json`. Bodygroup, модель, выбор точки спавна и позиция последнего выхода сохраняются между сессиями.
